# Official CK3 news reconciliation — 2026-11-03

## Scope, versions and result

This research covers **103 official Steam announcement entries published from 2025-01-01 through 2026-11-03**, plus **four targeted older modding diaries** (#55, #87, #126, #156). The API returned 490 entries across its longer history; this is feed coverage, not a guarantee that every forum-only reply is indexed. Complete returned bodies were scanned beyond titles. Original article bodies, scripts, screenshots, audio and video were not redistributed.

Three evidence baselines remain separate:

| Baseline | Evidence and permissible use |
|---|---|
| Historical **1.20.0.3 Crozier** | Existing engine exports, version lock, full-source reports and examples retain their original identity; no output is relabelled current |
| Installed **1.20.1.2 Crozier** | Launcher version captured before research; fresh current developer-reference/source audit supports narrow schema/caller findings, not fresh engine signatures or gameplay success |
| Forthcoming **Silk & Silver / 1.21** | Announcements, especially Diary #9; provisional implementation/migration guidance separated into a preview, without current-installation claims |

Read [released-news findings](../systems/news-modding-2025-2026.md) and [Silk & Silver preview](../systems/silk-and-silver-preview.md). Current chapter headers are dated precisely; existing older chapters are not blanket revalidated.

## Provenance and reproducible inventories

- [Catalogue](game-news-20261103/catalogue.json): source ID/GID, title, API-provided permalink, conventional Steam view URL, exact publication UTC, retrieval UTC, full-body hash, body length/line count, matching discovery lines and outgoing references.
- [Article coverage](game-news-20261103/article-coverage.md) and [structured coverage](game-news-20261103/article-coverage.json): every selected article's disposition, explanation, chapter destination, headings and source-only technical identifiers. Article status does not certify every identifier mentioned in it.
- [Native audit](game-news-20261103/native-audit.json): 1,286 current complete source files including 198 `.info` files, matching definitions/callers/localization/GUI/assets, helper edges and macro parameter surfaces. Matches to forecast terms are discovery only; absence from files is not proof of engine absence.
- [Wiki/tool comparisons](game-news-20261103/guide-checks.json), [forum access receipt](game-news-20261103/forum-checks.json), [preservation baseline](game-news-20261103/preservation-before.json) and [new verification](game-news-20261103/verification.json).

Tools use the official [Steam News API](https://api.steampowered.com/ISteamNews/GetNewsForApp/v2/?appid=1158310&count=1000&maxlength=0&feeds=steam_community_announcements). IDs `NEWS-<gid>` are stable within this collection. API-provided URLs are retained rather than relying solely on the moving news-feed page. Duplicate GIDs are checked. Separate preview/release articles are not discarded as duplicates merely because they discuss the same feature.

The source collector hashes each complete original body before extracting identifiers and metadata. Keywords are discovery aids: narrative-only, commercial and early vision articles receive explicit treatment instead of silently disappearing. Source-only identifier lists are **not** added to the engine declaration index or presented as valid command signatures. The older lookup tool continues to report its genuinely versioned sources.

## Source gaps and follow-up procedures

1. **Diary #188:** revisit its linked official forum article and developer responses when readable. Record post IDs, dates and exact attributable statements; compare with 1.18 release/patches/current files. The reachable Steam excerpt is not the full diary. Current files are independent evidence and cannot reconstruct missing commentary.
2. **Unspecified primitive contracts:** each source-only identifier is attached to an exact article, source hash and discovery span. Use lookup plus fresh version-matching dumps and complete native definition/caller/helper/parameter audit before promoting it into an API reference. Some declarations are screenshot-only or absent from the old exports; do not invent required fields.
3. **Preview implementations:** wait for available matching release files/exports; no game launch or engine-dump generation is authorized merely by this documentation operation. Reconcile renamed types and scope transitions, then create isolated examples and targeted runtime tests separately.
4. **Art/audio pipeline:** use actual current native consumer, schema, asset format and appropriate exporter/middleware documentation. The diary does not supply compression, bank/tool versions or redistribution permission. The Wiki sound warning about 1.16 is not a current version certification.
5. **Engine enforcement/performance/lifecycle:** test the named rule invocation, filters, absent/dead/destroyed targets, save/load, repeated execution, GUI scale/language and two-player outcomes where relevant. Existing runtime blockers remain open.

## Preservation and validation boundary

All authored changes stay under `Documentation`. Existing mods, installation files, settings, cache checkouts, engine exports, historical version locks and raw reports are preserved. New dated audit/verification outputs are separate; the legacy verifier's stale source hashes are reported as historical drift rather than repaired by overwriting its baseline.

This work performs research, complete source reads and static verification. **No game start, fresh engine export, gameplay, GUI rendering, audio playback, performance measurement, multiplayer test, tool installation or publication** was performed. Old user-run export sessions remain their own evidence class. See the new verification receipt for actual checked counts and any historical drift.
